# Sistem Peminjaman Buku (Patched) - Ready

## Setup
1. Import DB:
   mysql -u root -p < db/schema.sql

2. Start server from project root:
   php -S 127.0.0.1:8000 -t .

3. Open:
   - Frontend: http://127.0.0.1:8000/frontend/index.php
   - Backend admin: http://127.0.0.1:8000/backend/auth_login.php
